# 问答题

## 第 1 题

介绍一些在 C++ 中你常用的 STL 容器。

**答：** 我用的最多应该就是vector了吧，具有动态大小，相当灵活，很适合储存多维数据，用来储存一些临时数据也很好用；另外就是string，有许多独有特性，在文本处理，字符处理上相较于其它容器优势很大。还有就是array，在完成考核的过程中学到的，对于一般的c语言风格数组，它具有内置的边界检查，遇到越界访问会报错，而不是像c语言数组那样静默地破坏内存，并且可复制可返回可比较

## 第 2 题

你对 C++ 新标准有哪些了解，有哪些实用的特性，简要介绍一下。

**答：** 由于我的C++学习时间还较短，对于新特性的作用的理解还有限，以下是我认为即将发布的最新的C++26标准中比较吸引我的一些特性：

1. 合约(Contracts): 可以利用pre、post、contract_assert声明函数的前置条件、后置条件和断言，有利于错误检查
2. 内存安全优化(Less UB): 加强了vector等多种容器的边界检查，显著提升稳定性
3. std::inplace_vector: 相较于vector具有固定容量、无堆分配的特性，很适合用于需要严格控制性能的场景

## 第 3 题

为什么 C++ 需要预先编译而不能像 Python 一样直接运行，从源文件到可执行文件编译工具链做了哪些操作？ 

**答：** 因为python的"直接运行"其实是解释运行，类型判断和内存管理都在运行时完成，所以开发灵活，不用等待编译，但是会导致运行效率较低。相反，C++则需要在运行前也就是编译期去完成这些工作，所以具有较高的运行效率。从源文件到可执行文件，编译器做了以下操作:

1. 预处理：处理源代码中以"#"开头的指令，将#include的头文件内容完整插入到源代码中，并展开#define定义的宏
2. 编译：对预处理后的代码进行词法、语法和语义分析、构建抽象语法树，严格检查所有类型是否匹配，并基于已知的信息进行大量优化，最终生成汇编代码
3. 汇编：将汇编代码翻译成机器指令，打包成目标文件.obj
4. 链接：由链接器将所有目标文件和其所需库文件凭借在一起，经过符号解析(找到函数与变量的最终地址)和重定位(修正代码中的地址引用)后生成一个完整的可执行文件

## 第 4 题

在 Linux 中为什么要用 sudo，为什么不全程使用 root 账户？

**答：** 我认为这主要是一种防呆设计，相当于一次警告，告诉使用者该操作可能会引起严重事故，在linux这个相当自由的系统中，这点十分重要。不全程使用root在一定程度上可以阻挡恶意脚本等网络攻击对电脑造成的影响(虽然我觉得意义不大)，但主要还是降低误操作引发严重后果的可能性吧

## 第 5 题

在 RM 中算法组主要做什么工作，新赛季中有哪些规则变动属于算法组的工作？

**答：** 算法组的主要工作应该是去创造机器人的"大脑"，赋予机器人感知、决策和自主行动的能力，主要的方向有视觉、导航、机械臂三类。对于新赛季，算法组需要完成的工作应该有这些：

1. 做好重装机器人对于工作台标记、发射模块等的识别算法，及其机械臂的轨迹优化、装配状态的识别以及装配的决策逻辑
2. 自瞄视觉重做：由于机器人装甲由灯条加纸质的结构变为了点阵屏结构，需要重做视觉数据集，识别模型也需要重新训练
3. 根据全新的场地重建场地地图，解决新地图下的路径规划及动态避障问题，还有做好对于控制区占领的规划
4. 做好自定义终端，用算法分析场上局势，如控制区的占领情况等，为操作手提供合理的建议
